# Klarbefund : auto-évaluation

Protection des données, sécurité et statut réglementaire de l’application iPhone Klarbefund,
évalués par le projet lui-même au regard du code de [`clients/ios/`](../../clients/ios/) à la date du
2026-10-15. **Il s’agit d’une auto-évaluation, et non d’une certification, d’un audit ou d’un
avis juridique.** Chaque « satisfait » ci-dessous renvoie au code ou au test qui le démontre ;
tout ce qui n’est pas démontré est marqué ouvert. Les preuves d’exactitude figurent dans
[`evidence.md`](evidence.md) ; leur exécution sur un Mac est décrite dans [`run-on-mac.md`](run-on-mac.md).
Les références au code ci-dessous ont été vérifiées pour la dernière fois par rapport aux sources le 2026-10-15,
le jour même où les preuves ont été produites pour la dernière fois (voir le procès-verbal d’exécution dans
[`evidence.md`](evidence.md#run-record)).

Valeurs de statut : **satisfait** (implémenté et démontré dans le code ou les tests), **partiel**
(implémenté en partie, ou démontré uniquement par la conception), **ouvert** (non réalisé), **s.o.**
(sans objet pour cette application).

## Ce qui permettrait de clore les points ouverts

Réalisé le 2026-10-15, par le projet lui-même (voir
[`docs/security/security-test-report-2026-10-15.md`](../security/security-test-report-2026-10-15.md)) :
le modèle de menaces, le SBOM, une suite de tests de configuration et un test de sécurité
autoréalisé avec CodeQL, Semgrep, grype, trivy, gitleaks et des contrôles anonymes en
boîte noire du hub. Toujours ouverts :

1. Déclaration écrite de la destination et qualification selon le [MDCG 2019-11](https://health.ec.europa.eu/document/download/b45335c5-1679-4c71-a91c-fc7a4d37f12b_en), avec un
   avis externe sur la coloration des tendances.
2. Service d’explication hébergé : désigner l’exploitant comme responsable du traitement ou sous-traitant,
   signer le contrat de sous-traitance avec Azure (zone de données de l’UE, la valeur par défaut) et, pour
   l’option Anthropic sur adhésion, documenter la base de transfert ou la désactiver.
