# BSI-C5-Lückenanalyse: EHDS Integration Hub

**Standard**: BSI Kriterienkatalog Cloud Computing, [C5:2020](https://www.bsi.bund.de/SharedDocs/Downloads/EN/BSI/CloudComputing/ComplianceControlsCatalogue/2020/C5_2020.pdf?__blob=publicationFile&v=5) ([BSI-Seite](https://www.bsi.bund.de/EN/Themen/Unternehmen-und-Organisationen/Informationen-und-Empfehlungen/Empfehlungen-nach-Angriffszielen/Cloud-Computing/Kriterienkatalog-C5/C5_AktuelleVersion/C5_AktuelleVersion_node.html)). Für Prüfzeiträume, die am oder nach dem 1. Juni 2027 enden, empfiehlt das BSI [C5:2026](https://www.bsi.bund.de/EN/Themen/Unternehmen-und-Organisationen/Informationen-und-Empfehlungen/Empfehlungen-nach-Angriffszielen/Cloud-Computing/Kriterienkatalog-C5/C5_2025/C5_2025_node.html); diese Analyse ist noch nicht darauf umgestellt.
**Relevanz**: Kein Artikel der [Verordnung (EU) 2025/327](https://eur-lex.europa.eu/eli/reg/2025/327/oj/eng) nennt C5. [Art. 73 Abs. 1](https://eur-lex.europa.eu/eli/reg/2025/327/oj/eng#073.001) legt die Sicherheitsmaßnahmen der sicheren Verarbeitungsumgebung fest, [Art. 73 Abs. 3](https://eur-lex.europa.eu/eli/reg/2025/327/oj/eng#073.003) verlangt regelmäßige Audits, auch durch Dritte, und [Art. 73 Abs. 5](https://eur-lex.europa.eu/eli/reg/2025/327/oj/eng#073.005) überlässt die genauen Anforderungen Durchführungsrechtsakten, die bis zum 26. März 2027 fällig sind. C5 ist das, was ein öffentlicher Auftraggeber in Deutschland von der darunterliegenden Cloud verlangt ([Betriebsleitfaden, Abschnitt 3](operational-guideline.md#3-die-bsi-standards-teil-für-teil)); diese Analyse nimmt ihn als Maßstab für den Hub. Frühere Fassungen nannten „Art. 50(6)“, eine Nummer aus dem Vorschlag von 2022; der verabschiedete [Art. 50](https://eur-lex.europa.eu/eli/reg/2025/327/oj/eng#art_50) ist „Anwendbarkeit auf Gesundheitsdateninhaber“ ([Nummerierung](../ehds-article-numbering.md)).
**Umfang**: Bewertung von Demo/MVP. Ein echter C5-Bericht braucht einen akkreditierten Prüfer.

Jede Kriteriennummer verlinkt ihre Seite im PDF von C5:2020, und der Titel ist der des Katalogs, zitiert aus der englischen Fassung. Die Fassungen bis 2026-03-28 nutzten Nummern, die es in C5:2020 nicht gibt (CCM, IAM, DIP, LOG, INS), und gaben OIS-, DEV- und COS-Nummern Titel, die sie nicht haben; die Tabelle am Ende führt jede Änderung auf.

### Maßnahmen im Code ohne eigenes Kriterium

C5:2020 verlangt eine Richtlinie für sichere Entwicklung (DEV-01) und das Erkennen von Schwachstellen einschließlich statischer Analyse (PSS-02); für die folgenden Maßnahmen hat es kein eigenes Kriterium, sie sind die Belege des Hubs für beides:

| Maßnahme                                          | Demo-Status | Wo der Hub steht                                                                                                                                                                  |
| ------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Parametrisierte Abfragen                          | ✅          | Parametrisiertes Cypher, nie per String-Interpolation ([`api-conventions.md`](../../.claude/rules/api-conventions.md#query-patterns))                                             |
| Ausgabekodierung und eine Content Security Policy | ✅          | React maskiert die Ausgabe; eine CSP mit Nonce pro Anfrage und `strict-dynamic` ([`middleware.ts`](../../ui/src/middleware.ts#L88-L95))                                           |
| Keine Zugangsdaten im Code                        | ✅          | Umgebungsvariablen und Key-Vault-Referenzen ([ADR-036](../ADRs/ADR-036-operator-secrets-in-key-vault.md)); gitleaks wie unter PSS-02                                              |
| Datenminimierung                                  | ✅          | FHIR-Routen liefern nur die angefragten Felder; ein Grundsatz der DSGVO ([Art. 5 Abs. 1 Buchst. c](https://eur-lex.europa.eu/eli/reg/2016/679/oj/eng#005.001)), kein C5-Kriterium |
