# Beveiligingstestrapport, 2026-10-15

Een door het project zelf uitgevoerde beveiligingstest van de app Klarbefund
en de demohub, met de tools die de repository kan uitvoeren: statische
analyse, scans van afhankelijkheden en containers, scans op secrets,
configuratietests en anonieme black-box-controles van de live hub. **Het is
geen onafhankelijke penetratietest.** Wat zo'n test zou toevoegen, staat aan
het einde. Elk getal in dit rapport is reproduceerbaar met de vermelde
opdrachten; de ruwe rapporten van deze run zijn niet gecommit (ze bevatten
paden), de scripts wel.

## Wat een onafhankelijke test zou toevoegen

Dit rapport is het project dat zichzelf test met deterministische tools. Het
vervangt geen onafhankelijke penetratietest, en de zelfbeoordeling claimt
er ook geen. Zo'n test, door een door het BSI erkend laboratorium of
een ingehuurde tester, zou het volgende toevoegen:

1. **Een release-build op een apparaat**: inspectie tijdens runtime van de
   Keychain-items, de verzegelde opslag en de bestandsbeschermingsklassen met
   de telefoon vergrendeld en ontgrendeld; de kabeltest herhaald door iemand
   anders.
2. **Geauthenticeerde black-box-tests van de hub** in elk van de zeven rollen,
   tijdens kantooruren: horizontale toegang tussen patiënten
   (`refuseForeignRecord`), de reikwijdte van het app-token, rate limits onder
   belasting, de App Attest-verificatie met een opnieuw afgespeelde of
   vervalste attestatie.
3. **De eisenlijst van TR-03161 deel 1**, punt voor punt tegen het officiële
   document, die dit project alleen op het niveau van de groepen
   doelstellingen beoordeelt (`docs/klarbefund/self-assessment.md`).
4. **Een beoordeling van de configuratie van Keycloak en EDC** verder dan wat
   de openbare endpoints laten zien.

Tot die tijd luidt de status in de zelfbeoordeling "getest door het project,
onafhankelijke test open", en dit document is het bewijs voor de eerste helft
van die zin.
