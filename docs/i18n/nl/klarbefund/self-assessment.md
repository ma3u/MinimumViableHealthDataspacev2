# Klarbefund: zelfbeoordeling

Gegevensbescherming, beveiliging en regelgevingsstatus van de iPhone-app Klarbefund,
door het project zelf beoordeeld aan de hand van de code in [`clients/ios/`](../../clients/ios/) per
2026-10-15. **Dit is een zelfbeoordeling, geen certificering, geen audit en geen
juridisch advies.** Elke "voldaan" hieronder verwijst naar de code of test die dit aantoont;
alles wat niet is aangetoond, is als open gemarkeerd. Bewijs van de nauwkeurigheid staat in
[`evidence.md`](evidence.md); hoe u het op een Mac uitvoert, staat in [`run-on-mac.md`](run-on-mac.md).
De codeverwijzingen hieronder zijn op 2026-10-15 voor het laatst tegen de broncode gecontroleerd,
dezelfde dag waarop het bewijs voor het laatst is gegenereerd (zie het uitvoeringsverslag in
[`evidence.md`](evidence.md#run-record)).

Statuswaarden: **voldaan** (geïmplementeerd en aangetoond in code of tests), **deels**
(gedeeltelijk geïmplementeerd, of alleen door het ontwerp aangetoond), **open** (niet gedaan), **n.v.t.**
(niet van toepassing op deze app).

## Wat de open punten zou afsluiten

Gedaan op 2026-10-15, door het project zelf (zie
[`docs/security/security-test-report-2026-10-15.md`](../security/security-test-report-2026-10-15.md)):
het dreigingsmodel, de SBOM, een testsuite voor de configuratie en een zelf uitgevoerde
beveiligingstest met CodeQL, Semgrep, grype, trivy, gitleaks en anonieme
black-boxcontroles van de hub. Nog open:

1. Schriftelijke verklaring van het beoogde doel en kwalificatie volgens [MDCG 2019-11](https://health.ec.europa.eu/document/download/b45335c5-1679-4c71-a91c-fc7a4d37f12b_en), met een
   extern advies over de kleuring van de trends.
