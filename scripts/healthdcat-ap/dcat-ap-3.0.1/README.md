# DCAT-AP 3.0.1 SHACL, vendored

HealthDCAT-AP validates in two stages: first against DCAT-AP, the profile it
extends, then against its own health constraints (see "Validation of
HealthDCAT-AP" in the Release 8 specification). This is the first stage,
`dcat-ap-SHACL.ttl` of
[DCAT-AP 3.0.1](https://semiceu.github.io/DCAT-AP/releases/3.0.1/), from
`https://semiceu.github.io/DCAT-AP/releases/3.0.1/shacl/dcat-ap-SHACL.ttl`,
downloaded 2026-10-27, byte for byte; `SHA256SUMS` records it. DCAT-AP is
published by SEMIC under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
Used by [`../validate.py`](../validate.py) (#700).
